Architecture & Protocol Compliance

Built entirely without third-party frameworks or JDK HTTP built-ins.

Core Features

  • Raw Socket Layer: Non-delegated TCP socket management with connection pooling.
  • Strict HTTP/1.1 Parser: Hand-crafted stateful parser enforcing RFC 7230 line, header, and body specifications.
  • Conditional Requests: Evaluates If-Modified-Since and If-None-Match to serve fast 304 Not Modified responses.
  • Range Streaming: Single-range byte slicing serving 206 Partial Content with 8 KB chunking.
  • Persistent Connections: Fully supports Keep-Alive pipelining with request limits and idle timeouts.
  • Security Controls: Enforces canonical path boundary checks to prevent directory traversal exploits.
